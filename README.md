# AmneziaWG VPN одной командой

Скрипт ставит на чистый сервер VPN [AmneziaWG](https://docs.amnezia.org/) — это WireGuard с обфускацией, которую сложнее заблокировать — и сразу выдаёт конфиги для клиентов с QR-кодами.

- Сервер: **Ubuntu 24.04 или 22.04**, от 512 МБ RAM, доступ root по SSH.
- Клиенты: приложение **AmneziaVPN** или **AmneziaWG** (iOS, Android, Windows, macOS, Linux).

## Пошаговая инструкция

### 1. Арендуйте сервер

Любой VPS за границей с **Ubuntu 24.04**. После создания хостер даст **IP-адрес** и **пароль root**.

### 2. Зайдите на сервер

Откройте терминал на компьютере:
- **Windows** — «PowerShell» (Пуск → PowerShell);
- **macOS** — «Терминал»;

и выполните (вместо `1.2.3.4` — IP сервера):

```bash
ssh root@1.2.3.4
```

На вопрос `Are you sure you want to continue connecting` ответьте `yes`, затем введите пароль (символы при вводе не видны — это нормально).

### 3. Запустите установку

Вставьте одну команду и нажмите Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/Rodion4365/amnezia-vpn-installer/main/awg-vpn.sh | bash
```

Через 2–4 минуты скрипт покажет QR-коды трёх клиентов (`client1`, `client2`, `client3`) и инструкцию по скачиванию.

Нужно другое количество или свои имена:

```bash
curl -fsSL https://raw.githubusercontent.com/Rodion4365/amnezia-vpn-installer/main/awg-vpn.sh | bash -s -- install 5
curl -fsSL https://raw.githubusercontent.com/Rodion4365/amnezia-vpn-installer/main/awg-vpn.sh | bash -s -- install --names phone,laptop,mama
```

### 4. Подключите устройства

**Телефон** — установите AmneziaVPN (или AmneziaWG), нажмите «Добавить» → «QR-код» и отсканируйте код прямо с экрана терминала.

**Компьютер** — скачайте конфиги одним из способов.

*Способ А, через `scp`* — в **новом** окне терминала на своём ПК (не на сервере):

```bash
scp root@1.2.3.4:/root/awg-clients/vpn-configs.zip .
```

Архив появится в текущей папке (обычно это папка пользователя). Внутри — `.conf` для импорта и `.png` с QR-кодами.

*Способ Б, через браузер* — на сервере выполните:

```bash
awg-vpn share
```

Скрипт покажет ссылку вида `http://1.2.3.4:45678/…/`. Откройте её на ПК или телефоне — там все QR-коды и кнопка «Скачать всё». Ссылка работает 15 минут (или до Ctrl+C). Соединение не шифруется, поэтому закройте ссылку сразу после скачивания.

В приложении AmneziaVPN/AmneziaWG выберите «Импорт из файла» и укажите `.conf`.

## Управление

Всё делается на сервере командой `awg-vpn`:

| Команда | Что делает |
|---|---|
| `awg-vpn list` | клиенты, когда подключались, сколько трафика |
| `awg-vpn add masha` | добавить клиента и показать его QR |
| `awg-vpn remove masha` | удалить клиента |
| `awg-vpn qr masha` | показать QR ещё раз (без имени — все) |
| `awg-vpn share` | временная ссылка для скачивания в браузере |
| `awg-vpn status` | работает ли VPN |
| `awg-vpn uninstall` | удалить VPN с сервера |

Файлы клиентов лежат в `/root/awg-clients/`.

## Параметры установки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `N` | `3` | сколько клиентов создать |
| `--names a,b,c` | `client1..N` | имена клиентов (латиница, цифры, `-`, `_`) |
| `--port P` | случайный 30000–60000 | UDP-порт сервера |
| `--endpoint IP` | определяется сам | внешний IP или домен сервера |
| `--dns "…"` | `1.1.1.1, 8.8.8.8` | DNS для клиентов |
| `--subnet 10.8.0` | `10.8.0` | внутренняя подсеть VPN |

## Что именно настраивается

- Пакеты `amneziawg` из официального репозитория [ppa:amnezia/ppa](https://launchpad.net/~amnezia/+archive/ubuntu/ppa), модуль ядра через DKMS.
- Интерфейс `awg0`, сервис `awg-quick@awg0` (поднимается после перезагрузки).
- Для каждого сервера генерируются **свои** ключи и параметры обфускации (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1–H4`), поэтому одинаковых «отпечатков» у разных серверов нет.
- NAT, проброс трафика, ограничение MSS, BBR. Если включён `ufw`, порт открывается и в нём.
- Клиентам весь трафик (`0.0.0.0/0, ::/0`) идёт через туннель — IPv6 не утекает мимо VPN. MTU 1280.

## Запасной вариант через Cloudflare (на случай бана IP)

Если провайдер блокирует IP сервера целиком, AmneziaWG перестаёт работать. Скрипт `cf-vpn.sh` ставит **VLESS + XHTTP через Cloudflare CDN**: клиент подключается к адресам Cloudflare по вашему домену, а не к IP сервера, поэтому бан IP подключение не ломает. Скорость ниже, чем у AmneziaWG, но это хороший запасной канал.

Можно ставить на тот же сервер, что и AmneziaWG, — они не мешают друг другу (AmneziaWG — UDP, Cloudflare — TCP 80/443).

**Что нужно заранее:**

1. **Домен.** Любой дешёвый, без слов vpn/proxy в названии, не .ru/.рф. Например, на Namecheap; при покупке PremiumDNS не нужен, Domain Privacy оставьте.
2. **Аккаунт Cloudflare** (бесплатный): dash.cloudflare.com → *Add a domain* → ваш домен → план **Free**. Cloudflare покажет два NS-сервера — впишите их у регистратора (Namecheap: Domain List → Manage → Nameservers → **Custom DNS**).
3. В Cloudflare → **DNS → Records → Add record**: тип `A`, имя `@`, IPv4 — IP сервера, **Proxy status: Proxied** (оранжевое облако).
4. Подождите, пока домен станет *Active* (от 5 минут до пары часов).

**Установка** (на сервере, от root):

```bash
curl -fsSL https://raw.githubusercontent.com/Rodion4365/amnezia-vpn-installer/main/cf-vpn.sh | bash -s -- install --domain ваш-домен.com
```

Скрипт поставит Xray и nginx, выпустит сертификат Let's Encrypt, сделает «сайт-прикрытие» (если открыть домен в браузере, будет обычная страница входа) и закроет порты 80/443 для всех, кроме Cloudflare. В конце покажет QR-коды и ссылки `vless://…` для трёх клиентов.

**Приложения:** Happ, Hiddify, v2RayTun (iOS/Android), Hiddify или v2rayN (Windows/macOS) → «+» → сканировать QR или вставить ссылку из буфера.

Скачать ссылки и QR на ПК: `scp -r root@IP:/root/cf-clients .`

**Управление:** `cf-vpn list | add <имя> | remove <имя> | qr [имя] | status | cert | uninstall`

## Если что-то пошло не так

- **«Модуль ядра amneziawg не загрузился»** — выполните `apt install -y linux-generic && reboot`, после перезагрузки запустите установку снова.
- **VPN подключается, но сайты не открываются** — проверьте `awg-vpn status`; у некоторых хостеров нужно открыть UDP-порт в панели (файрвол хостера).
- **Перестало подключаться через какое-то время** — вероятно, заблокирован IP сервера. Возьмите у хостера новый IP или новый сервер и запустите установку заново.
- **Повторный запуск установки** ничего не ломает: если VPN уже стоит, скрипт просто покажет список клиентов.
